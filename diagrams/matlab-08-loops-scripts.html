Loops and Scripts

Write the steps once and let a loop run them for every participant.

1A for loop

A for loop runs the lines between for and end once for each value. On a single line, separate the parts with commas.

for i = 1:3, disp(i), end
for i = 1:3
    fprintf('Participant %d\n', i);
end

Each time around, i takes the next value: 1, then 2, then 3. The indenting is for the reader; MATLAB goes by for and end.

2Looping over participants

Put the sprintf template from lesson 4 inside a loop and you get every file name.

for s = 1:3
    fname = sprintf('sub-%02d.set', s);
    disp(fname)
end

3Lists of names: cell arrays

When participant IDs do not follow a pattern, keep them in a cell array, made with curly braces. A cell array can hold text of different lengths side by side.

subjects = {'sub-01', 'sub-02', 'sub-03'}
subjects{2}
subjects(2)
numel(subjects)

Braces take the text out: subjects{2} is 'sub-02'. Parentheses give back a smaller cell array, {'sub-02'}, which EEGLAB will not accept as a file name.

for s = 1:numel(subjects)
    fprintf('Next up: %s\n', subjects{s});
end

4Checking before you load

if runs lines only when a condition is true, and else handles the rest. Here the loop checks each file and skips the ones that are missing.

for s = 1:4
    fname = sprintf('sub-%02d.set', s);
    if isfile(fullfile('data', fname))
        fprintf('%s found\n', fname);
    else
        fprintf('%s is missing, skipping it\n', fname);
    end
end

5A script

A script is a file of commands that runs from top to bottom when you press Run or type its name. The Editor holds process_all.m. It loads each participant, filters the data, and saves a copy with _filt added to the name. Read it, press Run, and watch new files appear in the Current Folder (open data).

process_all
ls data

6When a script stops with an error

In the Editor, change 'sub-03' to 'sub-3', press Run, and read the message. It names the file MATLAB could not find and the line of the script where it stopped. Every line before that one already ran, so sub-01 and sub-02 were filtered and saved. Put the name back, and run it again.

In EEGLAB. The ERP pipeline labs build this kind of script one step at a time: filter, re-reference, cut epochs, mark artifacts, average. Once a step works for one participant, a loop runs it for all of them. See Plotting and Scripting in the ERP pipeline series.
