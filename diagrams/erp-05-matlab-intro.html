What you are looking at

    
The four panels of the MATLAB desktop. The Editor holds a script, a plain text file ending in .m that lists commands in order. The Command Window is where a single command is typed and answered. The Workspace lists every variable that currently exists, with its size and class. The Figure window is where plot draws. The Current folder on the left is where MATLAB looks for files. When a script that runs on one laptop fails on another, the usual cause is that this folder is different.

    
A variable is a named box. x = 5 creates a box called x and puts 5 in it, and the Workspace shows the box appear. An array is a row of boxes under one name: data = [1, 2, 3, 4, 5] makes five, and data(2) reads the second one, because MATLAB counts from 1. The colon operator builds long arrays without typing them, so t = 0:0.01:2 is 201 time points spaced 10 ms apart. A function takes inputs and returns outputs: sin(2*pi*t) hands the whole array to sin and gets a whole array back, and mean, size and plot work the same way. A comment begins with % and is for the human reading the script; MATLAB skips it.

    
Two small rules cause most early errors. A semicolon at the end of a line stops MATLAB from printing the result, so x = 5 echoes and x = 5; is silent. Names are case sensitive: Data and data are different boxes, and asking for one that does not exist produces the red "Undefined function or variable" message.

Why it matters for the pipeline

    
Every step of the ERP pipeline is a function call that takes the EEG variable in and hands a changed one back. EEG = pop_eegfiltnew(EEG, 0.1, []) has the same shape as y = sin(2*pi*t), with a bigger input and a longer name. The EEG struct is the same kind of variable as data: EEG.srate is a number, EEG.data is an array with one row per channel and one column per sample, and EEG.data(2, 1:5) is the first five samples of channel 2. A script is these calls written down in order. Once ten labs' worth of them are in one file, processing a second participant means changing one filename. The MathWorks documentation (The MathWorks, Inc., 2024) has a page for every function used here; the Lab 1 script in the editor is the one from the course.
